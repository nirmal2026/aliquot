# Envicron
Offline environmental laboratory & field calculator — 91 routines, 7 matrix pages.
Save as PDF generates a real PDF in-app (jsPDF, offline) and hands it to the native
Share sheet — choose "Save to Files" for a .pdf, or share to Drive/Gmail/WhatsApp.
Timestamps use the device's local timezone (IST on an India-set phone).
Not an official product. A calculation aid, not a validated method (ISO/IEC 17025:2017 §7.11.2).
