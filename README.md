# Envicron
Offline environmental laboratory & field calculator — 91 routines, 7 matrix pages.
Print / Save as PDF uses the native Android print dialog via @bcyesil/capacitor-plugin-printer
(choose "Save as PDF" for a real .pdf, or a printer). Share uses the native share sheet.
Not an official product. A calculation aid, not a validated method (ISO/IEC 17025:2017 §7.11.2).
