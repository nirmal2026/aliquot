# Envicron
Offline environmental laboratory & field calculator — 91 routines, 7 matrix pages.
Single-file web build wrapped in Capacitor for Android.
Not an official product. A calculation aid, not a validated method (ISO/IEC 17025:2017 §7.11.2).

## Build APK: Actions → Build Envicron APK → Run workflow. android/ is generated on the runner (gitignored).
