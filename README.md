# Envicron
Offline environmental laboratory & field calculator — 91 routines, 7 matrix pages.
Save as PDF generates a real PDF in-app (jsPDF, offline) → native Share sheet → "Save to Files".
Device-local timestamps (IST on an India-set phone). Symbols rendered ASCII-safe for PDF fonts.
Not an official product. A calculation aid, not a validated method (ISO/IEC 17025:2017 §7.11.2).
